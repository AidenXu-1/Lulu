# Provider logo sources

Retrieved 2026-09-24 from each provider’s public site and its declared icon / touch-icon URL, or from the official project / publisher repository. These are unchanged source files, not recreated artwork. Used only to identify the services in this local design preview. Brand marks remain the property of their respective owners; no ownership or endorsement is implied. No icon package or runtime dependency was added.

All provider and local model rails and detail headers share these files. Cloud transcription model rows identify the model’s publisher separately from the hosting service. Custom services retain a generic plus. Whisper uses OpenAI; SenseVoice uses the current official QwenAudio publisher mark; Qwen ASR/TTS use Qwen; IndexTTS 2/2.5 use the Bilibili site icon, as requested; VoxCPM2 uses OpenBMB. The IndexTTS GitHub account’s generated identicon was deliberately not used. Original aspect ratios and colors are retained; white MiMo and Agnes artwork is displayed on a dark backing in both themes.
