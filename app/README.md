`packaging/build_app.sh` 当前要求显式 `--identity`、`--venv`，以及绝对路径 `LULU_BUILD_ROOT`、`LULU_DIST_ROOT`；候选身份、通道及其他安全输入还需符合脚本检查。使用前先核对代码与本轮构建方案，不能复制旧命令直接运行。

| 目录 | 内容 |

| `src/core/`、`src/ui/` | 业务逻辑、界面和后台任务接入 |

## 产品边界

默认本地转录不上传音频或逐字稿，不加遥测；已有模型可离线运行。模型准备与链接下载属于用户主动发起的联网动作。可选云端转录必须明确告知音频会上传，文案处理及知识库集成也只在用户知情选择下发送所需内容。

主页采集默认按既有匿名公开数据规则；登录态采集是用户显式选择的独立例外，不自动读取浏览器凭据。本地配音沿用现有引擎，已有模型和运行时保留；实际就绪状态按当前机器核对，不能凭接口存在推断可用，也不从接班任务推断下载授权。
